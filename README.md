## 🧠 Topics Mastered (Days 1 – 52)

### 🔹 1. Core Basics & Control Flow (Days 1–20)
- **Fundamentals:** Variables, Data Types, Typecasting, User Inputs.
- **Strings:** Slicing, String Operations, Built-in String Methods.
- **Decision Making:** `if-else`, `elif` conditional ladders, `match-case` statements.
- **Loops:** `for` loops, `while` loops, range function, `break` & `continue`.

### 🔹 2. Data Structures & Functions (Days 21–35)
- **Functions:** Function arguments (default, keyword, variable-length), Docstrings, PEP 8 standards, Recursion.
- **Lists & Tuples:** Manipulations, List Methods, Comprehensions, Tuple operations & un-packing.
- **Sets & Dictionaries:** Set operations (union, intersection), Dictionary methods, looping through Key-Value pairs.
- **f-Strings:** Dynamic string formatting.

### 🔹 3. Error Handling & Modules (Days 36–45)
- **Exception Handling:** `try`, `except`, `finally`, raising custom exceptions.
- **Scope & Modules:** `import` working mechanism, `if __name__ == "__main__"`, Local vs. Global variables.
- **Short Hand Syntax:** Single-line `if-else`, `enumerate()` function.

### 🔹 4. Advanced Foundations & File I/O (Days 46–52)
- **File Handling:** Reading/Writing files (`open`, `read`, `write`, `append`), using `with` statement.
- **File Pointer Control:** `seek()`, `tell()`, `truncate()` methods.
- **Functional Programming:** `lambda` functions, high-order functions (`map()`, `filter()`, `reduce()`).
- **Identity vs Equality:** Deep dive into `is` vs `==`.
